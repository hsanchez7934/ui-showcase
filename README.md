# UI Components Showcase

A curated library of production-ready UI views and components built to demonstrate front-end craftsmanship—reusable patterns, strong UX, accessibility, and performance-minded code.

**Live demo:** [https://ui-showcase-three.vercel.app/](https://ui-showcase-three.vercel.app/)

Each page includes an isolated demo you can browse from the landing page or the site navigation. Featured views include hero sections, feature grids, pricing layouts, media cards, team sections, collections grids, and a custom 404 page.

## Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Material UI](https://mui.com/) (select components)
- [React Icons](https://react-icons.github.io/react-icons/)

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the app locally.

## Scripts

| Command        | Description              |
| -------------- | ------------------------ |
| `npm run dev`  | Start the dev server     |
| `npm run build`| Create a production build|
| `npm run start`| Run the production build |
| `npm run lint` | Run ESLint               |
